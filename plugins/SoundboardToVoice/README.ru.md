# SoundboardToVoice

[English](README.md) | **Русский**

Пользовательский плагин для [Vencord](https://vencord.dev), который проигрывает звуки саундборда Discord **через ваш микрофон**.
Вы нажимаете на звук в обычной панели саундборда, а участники голосового канала слышат его как часть вашего голоса.

Звук не проходит через саундборд Discord, поэтому плагин работает:

- без Nitro, в том числе со звуками с других ваших серверов;
- в каналах, где у вас нет прав «Использовать звуковую панель» и «Использовать внешние звуки»;
- на серверах, в личных и групповых звонках.

Работает в официальном приложении **Discord Desktop**, а также в Vesktop и в браузере.

> [!WARNING]
> Модификации клиента нарушают Условия использования Discord, а этот плагин намеренно обходит платную функцию и серверное право. Используйте на свой риск и уважайте правила серверов, на которых находитесь.

## Как это работает, коротко

Обычно Discord Desktop захватывает микрофон в нативном модуле, к которому у JavaScript нет доступа. Плагин переключает голос на собственный WebRTC-движок Discord (тот, что используется в браузерной версии), где микрофон — обычный поток Web Audio. Затем плагин оборачивает этот поток, подмешивает в него звук и следит, чтобы ваш статус «говорит» оставался верным, пока звук играет.

Подробнее: [docs/ru/how-it-works.md](docs/ru/how-it-works.md).

## Что нужно

- Vencord, **собранный из исходников**. В версию, поставленную готовым установщиком, пользовательские плагины добавить нельзя. См. [инструкцию Vencord](https://docs.vencord.dev/installing/).
- git, Node.js и pnpm (они уже есть, если вы собирали Vencord).

## Установка

1. Откройте терминал в папке Vencord и склонируйте плагин в `src/userplugins`. Если такой папки нет, создайте её.

   ```bash
   cd src/userplugins
   git clone https://github.com/Nanda070/SoundboardToVoice soundboardToVoice
   cd ../..
   ```

2. Соберите Vencord.

   ```bash
   pnpm build
   ```

   Если эта сборка Vencord ещё не подключена к Discord, выполните также `pnpm inject`.

3. Полностью перезапустите Discord (выйдите через значок в трее).
4. Откройте **Настройки → Vencord → Plugins**, включите **SoundboardToVoice** и согласитесь на перезапуск.
5. Если у вас включён **SoundboardPermissionsBypass**, выключите его. Оба плагина изменяют один и тот же код и конфликтуют.

## Обновление

```bash
cd src/userplugins/soundboardToVoice
git pull
cd ../../..
pnpm build
```

После этого перезапустите Discord.

## Использование

Зайдите в голосовой канал, откройте саундборд, нажмите на звук. Это всё.

- Остальные слышат звук от вас, с той громкостью, которую они выставили вам. Анимацию саундборда они не видят.
- Когда вы в муте, звук всё равно отправляется (микрофон остаётся выключенным). Это можно отключить.
- В режиме рации (push to talk) клавишу держать не нужно: плагин сам открывает передачу на время звука, а микрофон остаётся закрытым, пока вы действительно не зажмёте клавишу.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Volume | 100% | Громкость звуков для остальных (0–200%). |
| Hear Sounds | вкл | Проигрывает звук и вам, с громкостью саундборда из настроек Discord. |
| Play While Muted | вкл | Отправляет звуки, когда вы выключили микрофон. |
| Unlock All Sounds | вкл | Показывает звуки со всех ваших серверов в любом канале. Нужен перезапуск. |
| Force WebRTC | вкл | Только Discord Desktop: голос идёт через WebRTC-движок. Там это обязательно. Нужен перезапуск. |

## Ограничения

- **WebRTC-движок — не нативный движок.** В Discord Desktop набор настроек шумоподавления может отличаться (Krisp может быть недоступен), а функции, завязанные на нативный движок, — звук демонстрации экрана, клипы, внутриигровой оверлей — с этим плагином не проверялись. Если сломалось что-то нужное, выключите *Force WebRTC* или сам плагин и перезапустите Discord.
- **Обновления Discord могут сломать плагин.** Он изменяет минифицированный код Discord. Когда патч перестаёт совпадать, Vencord пишет предупреждение, и соответствующая часть не работает, пока патч не исправят. См. [Решение проблем](#решение-проблем).
- Серверный мут и роль «слушателя» на трибуне по-прежнему глушат вас целиком, вместе со звуками.
- Vesktop и браузер должны работать (там и так используется WebRTC-движок), но проверялся только Discord Desktop на Windows.

## Решение проблем

**«Join a voice channel before playing a sound»**, хотя вы в канале: плагину не во что подмешивать звук. В Discord Desktop проверьте, что *Force WebRTC* включён и что вы перезапустили приложение. Если плагин только что включён, выйдите из канала и зайдите снова.

**Статус завис на «Authenticating»** или появилась плашка **«Video and Screen Share are not supported in this browser»**: один из патчей движка больше не применяется. Запустите проверку патчей (ниже).

**Ничего не происходит или другие не слышат звук**: откройте консоль (`Ctrl+Shift+I`), найдите предупреждения Vencord с упоминанием `SoundboardToVoice`, затем запустите проверку патчей.

### Проверка патчей

Показывает, какой патч сломался после обновления Discord, не запуская сам Discord. Скрипт скачивает текущий веб-бандл Discord, применяет к нему все патчи и проверяет, что результат остался корректным JavaScript.

```bash
node tools/check-patches.mjs
```

Для других каналов обновлений есть `--channel canary` и `--channel ptb`. Нужен Node.js 22.18 или новее.

## Разработка

```bash
node --test "tests/*.test.mjs"   # модульные тесты: микшер, кэш звуков, замены в патчах
node tools/check-patches.mjs     # патчи на актуальном бандле Discord
```

Файлы:

| Файл | Назначение |
|---|---|
| `index.ts` | Описание плагина, связывание частей, точка входа `playSound`. |
| `patches.ts` | Все патчи webpack, сгруппированные по назначению. |
| `mixer.ts` | Подмешивает звуки в поток микрофона; правила для статуса «говорит», мута и рации. |
| `sounds.ts` | Загружает и кэширует файлы звуков. |
| `settings.ts` | Настройки плагина. |
| `tools/` | Проверка патчей. |
| `tests/` | Модульные тесты, запускаются обычным Node.js. |
